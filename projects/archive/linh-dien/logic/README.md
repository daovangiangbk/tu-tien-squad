# Logic — Linh điền

Arc/beats slice-of-life + hữu tình nhẹ: xem `00-master-brief.md` §4–§6.

### Thuật ngữ work (Logic → prose)

| Rút gọn cũ | Viết đủ trong tài liệu `linh-dien` |
| --- | --- |
| **ca** | **ca làm việc trên linh điền** — một buổi lao động có **ký sổ** (sáng sớm / giữa ngày giờ Ngọ / chiều); linh nông phàm nhân và MC **cùng ca làm việc** khi cần. **Không** dùng **ca** một mình. |
| **ca linh nông phàm nhân** | ca làm việc do **linh nông phàm nhân** trực (cuốc, gieo, hái…) |
| **buổi tu luyện** | Khác **ca làm việc** — MC **không** bế quan / tu show-off trên điền arc này |
| **phàm** | **Không** viết *phàm* một mình chỉ người. Dùng **phàm nhân**, **linh nông phàm nhân**, hoặc **tên / vai** cụ thể (sau naming). |
| **bạc** | Tiền **phàm nhân** (Luật 6b). **Không** viết *bạc phàm*. |
| **mương** | **Mương tưới** — rãnh / kênh nước nhỏ giữa các luống. Logic: *mở mương tưới*, *dẫn nước mương tưới*; **không** viết *mương* một mình. |
| **van** | **Cấm** cho chắn nước tre trong mương (nghe hiện đại). Dùng **ván tre** — tấm tre hạ/nhấc chia dòng; kẹt thường do lá, bùn, cát — **không** bôi mỡ lên ván. Mỡ/thoa chỉ cho **khớp nước** (đồng/sắt) rỉ kẹt, nếu có trên điền. |
| **tre giới** | **Cấm trong prose.** Không viết tắt/ám chỉ. Dùng: **hàng tre** (trồng dọc sườn, che gió, ngăn linh ngư với điện tông); *dưới gốc hàng tre ven luống*; *hàng tre dưới Ngưng Lộ Điện*. |
| **Z-1…Z-5** | Chỉ **sổ tông / quyển riêng MC** (vd. *Z-2, lá phụ thu*). Prose: **Z-1** → **luống ngoại** · **Z-2** → **luống gió** · **Z-3** → **đài mẫu** / **đài Cửu Diệp Chi** · **Z-4** → **ao rửa** + **giàn phơi linh dược** · **Z-5** → **kho** — không ghi mã zone trong thân chương. |
| **Linh-** thừa | Bối cảnh đã là **Linh Giới**, **linh điền** — nước, khí, phân trên ngư **mặc định** mang linh tính. **Prose:** **phân bón**, **phân ủ**, **tro**, **nước**, **mương tưới**…; **không** gượng *linh phân*, *linh thủy* trừ khi đối chiếu rõ với thứ **không** linh (vd. *không phải linh trà*). **Giữ:** **linh thảo**, **linh dược** (loại cây / hàng trên điền — vd. **giàn phơi linh dược**, **Thanh Linh Thảo**). **Logic/sổ** vẫn có thể ghi *linh phân*. |
| **Tên linh thảo viết tắt** | **Cấm trong prose/thoại** (`interface/chapters/**`). Không *Thanh*, *Phong*, *Ngũ Sắc*, *Cửu Diệp* một mình — dùng tên đủ **registry** (vd. **Thanh Linh Thảo**, **Phong Linh Thảo**, **Ngũ Sắc Linh Quả**, **Cửu Diệp Chi**, **Sa Hoàng Quả**). Quyển riêng MC có thể rút một chữ *nếu* ngữ cảnh sổ tay rõ (ưu tiên vẫn đủ tên). |
| **Thanh niên** | **Cấm** gọi nhân vật phụ — dễ nhầm **Thanh Linh Thảo**. Dùng **người trẻ trong ca làm việc**, **một người trẻ**, **lão trong ca**; **MC = Thường An (Thường An)**. |

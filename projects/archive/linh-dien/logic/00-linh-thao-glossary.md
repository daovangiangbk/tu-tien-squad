# Glossary linh thảo — Linh điền (work)

| Trường | Giá trị |
| --- | --- |
| **work_slug** | `linh-dien` |
| **Lớp** | Logic — canon work (arc 1) |
| **Neo Foundation** | [`foundation/resources/02-linh-duoc.md`](../../../foundation/resources/02-linh-duoc.md) · Luật 2 dược · [`10-phu-nghe-tu-tien.md`](../../../foundation/resources/10-phu-nghe-tu-tien.md) §3.5 |
| **Neo work** | [`world/00-micro-linh-dien-setting.md`](world/00-micro-linh-dien-setting.md) §2–§4 · [`chapters/00-chapter-spine-linh-dien.md`](chapters/00-chapter-spine-linh-dien.md) |
| **Trạng thái** | `canon` (Logic) — prose tra cứu, không bài giảng trong chương |

**Phạm vi:** Mọi **linh thảo / linh dược** xuất hiện hoặc **dự kiến** trên linh điền work này. Chi tiết **trồng–chăm–thu–sơ chế** = tầng điền tông nhỏ (khác nguồn gốc toàn giới trong `02`).

**Quy ước chung (mọi loài trên điền)**

| Mục | Quy tắc work |
| --- | --- |
| **Sai kỳ / sai tay** | Thu hái, phơi, bón, tưới sai → **dược tính giảm**; có thể đan độc nhẹ (Luật 2). MC **sửa bằng công**, không linh lực ép. |
| **Sơ chế sau thu** | Rửa (ao Z-4) → phơi/sấy (giàn Z-4) → cắt → ngọc giản / bao · tem cống hiến → giao **Đan các** tông. |
| **Trận** | **Tụ Linh Tiểu Trận** (Z-1→Z-3); Z-2 thêm **trận gió nhẹ**; Z-1 **trận cách trùng** theo mùa. |
| **Đơn vị thời gian** | **Kỳ** = chu kỳ từ gieo/trồng đến một lần thu có dược tính; **vụ** = một mùa canh tác trên luống. |

## I. Trên linh điền arc 1 — hồ sơ đầy đủ

### 1. Thanh Linh Thảo (青灵草)

| Mục | Nội dung |
| --- | --- |
| **Phân khu** | **Z-1** — luống ngoại, linh khí **yếu**, **Mộc** thiên, ẩm vừa |
| **Công dụng** (`02`) | **Tụ Khí Đan** hạ phẩm; phù **Thanh Phong** |
| **Hiếm (toàn giới)** | Thấp — linh điền ngoại môn |
| **Kỳ sinh trưởng** | **3–5 năm** / một lần thu lá đạt dược tính (work: có thể **hái lá non** theo vụ, **rễ/hạt** gieo lại) |
| **Đặc tính quan sát** | Lá **thanh**, mùi **tươi** khác hẳn lô **khô**; sương sớm đọng **mỏng** trên mép lá |
| **Gieo / trồng** | **Xuân** — gieo hạt hoặc cấy mầm; **không** dày quá (work: ~ một nắm tay / sảnh luống `[giả định]`) |
| **Chăm · bón** | **Phân bón** / tro (Logic: *linh phân*) **vừa** theo sổ; **cách trùng** mùa; cỏ tranh **nhổ tay** · prose: `logic/README.md` **Linh-** thừa |
| **Tưới** | **Mương tưới** sáng sớm; luống ẩm vừa — **úng** nếu tưới dồn |
| **Thu hoạch** | **Thu** — lá đủ kỳ; hái **sớm/muộn** → dược tính giảm |
| **Sơ chế** | Phơi Z-4 → cắt → đóng bao; giao **Đan các** |
| **Rủi ro điền** | Mưa **trôi hạt**; **bón dư** → mầm vàng úa; sâu linh / sâu thường |
| **Arc / spine** | Ch.1 gieo · ch.2 bón dư · ch.4 tưới lẫn · ch.7–8 phơi |

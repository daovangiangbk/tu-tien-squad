# Foundation / Logic Layer

**Logic (Điều phối)** biến **Core (Nền tảng)** thành mạch truyện: arc, xung đột, pacing, phục bút — **không** thêm luật tu luyện mới trái `foundation/core/03-power-system-economy-core.md`, **không** phá `(invariant)` trong `foundation/core/02-world-laws-lore-core.md`.

| Lớp | Vai trò | Ví dụ trong repo |
| --- | --- | --- |
| **Foundation / Core** | Theme, luật thế giới, hệ tu & kinh tế | `foundation/core/01–03`, `foundation/resources/` |
| **Logic** | Quy mô sự kiện, phân loại arc, checklist outline | `foundation/logic/01-event-scale-system.md` |
| **Interface** | Chương, văn phong, cliffhanger | (tác phẩm) |

**Luồng làm việc:** Sửa Core khi luật/tài nguyên đổi → outline arc bằng Logic → viết chương Interface.

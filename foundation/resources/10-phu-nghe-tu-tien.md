## 1. Khung chung

### Vai trò trong giới

| Khía cạnh | Mô tả `(invariant)` |
| --- | --- |
| **Kinh tế** | Phụ nghề **ràng buộc** tu sĩ với tông / hội / thương thành — đan, khí, trận, phù là **hàng chiến lược**, không chỉ loot. |
| **Cống hiến** | Trong tông (§7 nguồn): **Đan các, Khí các, Trận các, Phù các** tranh **điểm cống hiến** với nhiệm vụ ngoại môn; tạp dịch làm việc phụ. |
| **Monopoly** | Công thức **Thiên+**, trận hộ sơn, phù Thiên — tông / **Luyện Đan Sư Hiệp Hội** / gia tộc; tán tu chủ yếu **Hạ–Địa** hoặc mua đúc sẵn. |
| **Cảnh giới sư** | Phụ nghề **không thay** trần tu vi chiến đấu — đan sư Kim Đan vẫn có thể thua Trúc Cơ chiến tu; **phẩm sản phẩm** gắn **cảnh giới + hạng sư**. |
| **Tiêu hao thi triển** | Tu sĩ vận hành phù / trận / pháp bảo vẫn hao **linh khí, thần thức, thể lực** (`09` §0); sư **chế tạo** hao vật liệu + linh lực / thần thức khi luyện. |

### Hạng sư (ước — dùng thống nhất catalog)

**Hạ → Trung → Thượng → Đại sư → Tông sư** (tương đương phẩm công pháp **Hoàng → Huyền → Địa → Thiên → Tiên** cho **sản phẩm tối đa** sư đó luyện được ổn định).

| Hạng sư | Sản phẩm điển hình (ước) | Cảnh giới sư (thường) |
| --- | --- | --- |
| Hạ | Pháp khí hạ, phù hạ, đan Tụ Khí | Luyện Khí–Trúc Cơ |
| Trung | Pháp khí trung, phù trung, Trúc Cơ đan phẩm | Trúc Cơ–Kim Đan |
| Thượng | Linh khí, phù thượng, Kim Đan hỗ trợ | Kim Đan |
| Đại sư | Cổ bảo hạ, trận Địa, phù Cực / Thiên Phù hạ | Nguyên Anh |
| Tông sư | Cổ bảo+, hộ sơn đại trận, đan Hóa Thần hỗ trợ | Hóa Thần+ (hiếm ở Hạ Giới) |

## 3. Chi tiết nghề cốt lõi (V2 §8)

### 3.1. Luyện đan (炼丹) — Đan sư

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Thu thập / mua linh dược → luyện trong **lò đan** → đan hoàn. |
| **Cảnh giới sư** | Luyện Khí có thể học **Tụ Khí** (Hạ); **Trúc Cơ Đan** cần sư **Trung+** (Kim Đan đan sư phổ biến). |
| **Vật liệu** | Linh dược (`02`), linh hỏa / địa hỏa, lò (`05` Thiên Hỏa Lô), **linh thạch** duy trì lửa. |
| **Kinh tế** | **Trúc Cơ Đan** = then chốt (`03`); **Luyện Đan Sư Hiệp Hội** định giá & chứng nhận; đan phương monopoly (`04`). |
| **Trade-off** | Thất bại → nổ lò, đan độc; luyện Ma đan → **Nghiệp**; đan sư chiến yếu → cần hộ vệ. |
| **Tán tu** | Mua đan; hiếm có đan sư đỉnh giữ **phương lậu** (hook `02` §6). |

### 3.2. Luyện khí (炼器) — Khí sư

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Rèn **pháp khí → linh khí → cổ bảo**; sửa pháp bảo tàn; chế **trận đĩa**, túi trữ. |
| **Cảnh giới sư** | Trúc Cơ+ mới ổn định linh khí; cổ bảo cần Kim Đan+ & bí pháp Thiên. |
| **Vật liệu** | Huyền thiết, linh sa, yêu cốt, **Hỗn Độn Thạch** (hiếm), linh thạch luyện. |
| **Kinh tế** | Nuôi khí pháp bảo = **dòng linh thạch dài hạn** (`05`); tông giữ khí sư **Đại sư** để monopolize trang bị nội môn. |
| **Trade-off** | Thất bại → phế khí; Ma luyện (**Huyết Sát Phi Kiếm**) → Nghiệp. |

### 3.3. Trận pháp (阵法) — Trận sư

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Thiết kế trận đồ, bố trí **阵眼**, duy trì hộ sơn / truyền tống; **合阵** chiến. |
| **Cảnh giới sư** | Trúc Cơ+ tiểu trận; hộ sơn đại trận cần Kim Đan–Nguyên Anh trận sư + **linh mạch**. |
| **Vật liệu** | Trận kỳ, linh thạch, linh mẫu, trận đĩa (`05`, `08`). |
| **Kinh tế** | Dự án **tiêu hao lớn** (`03` §3.7); tranh cống hiến với Đan / Phù; Sát Thủ Các thuê trận **hợp đồng**. |
| **Trade-off** | Phá **阵眼** = sụp trận; trận Ma / huyết → Nghiệp; hút mạch quá mức → World Luật 7. |

→ Chi tiết trận: **`08-tran-phap.md`**.

### 3.4. Phù lục (符箓) — Phù sư

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Vẽ / đúc phù; **mực linh**, da yêu, linh sa. |
| **Cảnh giới sư** | Luyện Khí vẽ phù hạ; phù Thiên cần Kim Đan+ phù sư. |
| **Kinh tế** | Phù đúc sẵn = hàng **ngoại môn & tán tu**; phù cao = cống hiến tông (`06`). |
| **Trade-off** | Phù Ma (**Huyết Sát**, **Đoạt Hồn**) → Nhân-Quả; một lần tiêu hao — áp lực túi tiền. |

→ **`06-phu-luc.md`**.

### 3.5. Linh điền (灵田) — Linh nông

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Trồng **linh cốt thảo**, Tuyết Lớp, Cửu Diệp Chi…; thu hoạch theo mùa / linh khí. |
| **Cảnh giới** | Phàm có thể làm **ngoại môn**; quản lý điền **Trúc Cơ+** (trận tụ linh tiểu). |
| **Vật liệu / điều kiện** | Linh mạch yếu–trung, linh thạch bón, **trận tụ linh** (`08` Tụ Linh Tiểu Trận). |
| **Kinh tế** | Gia tộc / tông **sở hữu điền**; tranh **hạt giống** & địa; nghẽn đan = khan linh dược. |
| **Trade-off** | Sơn lâm yêu phá điền; chiếm điền = chiến tranh (Luật 7). |

### 3.6. Sủng thú (灵兽 / 御兽)

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Thuần phục, nuôi **linh thú / yêu thú** cấp thấp; khế ước; hộ vệ, vận tải, dò khí. |
| **Cảnh giới sư** | Trúc Cơ+ khế thú Trúc Cơ tương đương; Kim Đan thú cần sư Kim Đan+. |
| **Kinh tế** | **Yêu đan** từ thú chết = tranh nhân–yêu (`07`); tông bán **sủng thú đệ tử**. |
| **Trade-off** | Phản chủ; thú chết; Ma **nuốt yêu đan** shortcut — Nghiệp. |

### 3.7. Bói toán (天机 / 卜筮)

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Quan **Thiên cơ**, la bàn, quẻ; dự **hung cát** mở bí cảnh, đột phá, hợp tác. |
| **Cảnh giới sư** | Luyện Khí+ (mịch suốt); cao cấp cần **Mệnh Lực** / Thần thức (`02` Luật 1). |
| **Kinh tế** | Bán **tin** = ngang giá trị linh thạch (Bách Hóa, Sát Thủ Các); `(bí mật)` che giấu **tọa độ bí cảnh**. |
| **Trade-off** | **Nghịch Thiên** đoán sai → Nhân-Quả; lạm dụng Mệnh Lực → giảm thọ / tâm ma. `(invariant)` Bói **không thay** kiếp nạn — chỉ giảm rủi ro thông tin. |

### 3.8. Tạp tu (杂修)

| Trục | Nội dung |
| --- | --- |
| **Công việc** | Mọi việc **không đủ chuyên**: hộ tống, quét sơn môn, vận linh thạch, phụ tá đan / khí / trận. |
| **Cảnh giới** | Thường Luyện Khí–Trúc Cơ; có thể võ tu Luyện Thể. |
| **Kinh tế** | **Điểm cống hiến** thấp; bước vào phụ nghề chính khi có sư nhận. |
| **Trade-off** | Không monopoly kỹ năng — dễ thay thế; tán tu nhiều người từng là tạp dịch / ngoại môn. |

## 4. Nghề mở rộng & xám

| Nghề | Ghi chú nhanh |
| --- | --- |
| **Điển tịch sư** | Giải **mảnh cổ** → đan phương / công pháp; tông **không chia sẻ** miễn phí. |
| **Thái dược / Dược điêu** | Nghề vào cửa **linh điền & đan**; rủi ro cấm địa, yêu thú. |
| **Đào bảo tu** | Gắn **tán tu**, bí cảnh chu kỳ; thuê **Trận sư / Sát Thủ Các**. |
| **Thương tu** | **Luật thành trì** (Luật 3); vận **linh thạch** = mục tiêu cướp. |
| **Thể dược sư** | Hỗ trợ **Luyện Thể** — không thay linh căn. |
| **Quỷ tu / Độc sư** | Ma / Tà; **Quỷ Doanh**, **Độc Phái**; plot hook đan trong thành (`02` §6). |

## 5. Phụ thuộc phe (sketch)

```
                    [ Danh môn: Đan / Khí / Trận / Phù các ]
                                    |
          +-------------------------+-------------------------+
          |                         |                         |
   [ Luyện Đan Sư Hiệp Hội ]  [ Bách Hóa Đường ]     [ Gia tộc: linh điền + khí sư ]
          |                         |                         |
          +-------------------------+-------------------------+
                                    |
              [ Ngoại môn / Tạp dịch / Thái dược / Thương tu ]
                                    |
              [ Tán tu: đa nghề mảnh + mua đúc sẵn ]
                                    |
              [ Hắc thị: Ma đan, Quỷ khế, đan phương lậu ]
```

| Phe (kiểu §6) | Nghề nổi bật |
| --- | --- |
| Chính đạo danh môn | Đan / Trận / Khí **monopoly**; linh điền tông |
| Ma đạo | Ma đan, huyết luyện, quỷ phù, độc |
| Trung lập | **Luyện Đan Hiệp Hội**, Bách Hóa, đấu giá, **Sát Thủ Các** (không phải phụ nghề nhưng thuê mọi nghề) |
| Yêu tộc | Sủng thú ngược; săn **linh nông / dược điêu** |
| Tán tu | Thái dược, đào bảo, phù mua ngoài; hiếm **Đại sư** |

## 6. Liên kết Logic Layer (gợi ý, không viết arc)

- Đệ tử chọn **một phụ nghề chính** → ràng buộc sư phụ / các trong tông.
- **Công tích** đổi **đan / phù / khí** — plot tranh **Đan các**.
- Tán tu đỉnh: **đa nghề mảnh** (phù + pháp bảo) bù thiếu đan tông — sync `02` Tán tu.
- `(bí mật)` Thiên cơ sư biết **mở sớm bí cảnh** → tranh với Bách Hóa.
